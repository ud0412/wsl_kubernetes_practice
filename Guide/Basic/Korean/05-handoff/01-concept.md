# 05 설명 — 자동 구축과 후속 과정의 시작점

자동 스크립트는 수동 과정의 설정과 같은 구성 요소를 적용합니다. 선행 환경을 한 번에 준비한 뒤 Observability를 배우고 싶은 경우에 사용합니다.

다른 저장소로 이동해도 같은 WSL 사용자, 클러스터 이름, kubeconfig, 관리 데이터 폴더를 사용합니다. 후속 과정이 준비 상태를 검사한 뒤 관측 도구만 추가합니다.

기반 클러스터 소유권과 전체 삭제 구현은 이 저장소가 담당합니다. 후속 과정의 destroy도 이 구현을 호출합니다. 두 과정의 실습 데이터가 한 환경에 있으므로 전체 종료는 Kubernetes까지 제거합니다.
